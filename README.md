# darts-form — ダーツフォーム解析

タブレットのカメラで3投を撮影し、刺さった位置と合わせて投球フォームを解析するブラウザアプリです。

**アプリを開く：** https://boyeojulgae.github.io/darts-form/

## 使い方

1. タブレットのChromeで上のURLを開き、カメラを許可します。
2. メニューの「ホーム画面に追加」（または「アプリをインストール」）で、全画面のアプリとして起動できます。
3. 最初に設定で利き手と身長を入れます。
4. 顔と投げる腕の肘までが映るようにタブレットを置き、「スタート」を押します。
5. 準備時間のあと、合図に合わせて1投ずつ（1投5秒）投げます。
6. ダーツ盤の画面で、刺さった位置を1投目から順にタップして「決定」を押します。近くに刺さった時は、2本指でつまむか「＋」で盤面を拡大できます。
7. 「認識の確認」画面で、肩・肘・手首の丸が体の位置と合っているかを見ます。ずれていたら丸をドラッグして直し、「この内容で解析する」を押します。
8. 解析結果を確認し、「保存して次へ」で履歴にためます。15投以上たまると、動きと外れ方の関係を表示します。

## カメラ

- 設定の「カメラ」には、ブラウザが認識しているカメラだけが並びます。外付けのUSBカメラは、つないで認識されると自動で追加されます。
- 外付けカメラが一覧に出ない場合、タブレット（Android）側がUSBカメラをブラウザに渡していません。その場合、このアプリからは使えません。
- カメラを開くと、そのカメラの上限を調べて画質とコマ数を設定します。「自動」はフルHDまでで一番きれいな画質を選び、その中で一番多いコマ数にします。「コマ数を優先」「カメラの最高解像度」も選べます。実際の設定はホーム画面の「カメラ」の行に表示されます。
- ほかのアプリに切り替えるとカメラを止め、戻った時に開き直します。映像が止まったままの時も自動で開き直します。

## 認識の確認と3投の比較

- 姿勢の自動認識は、手首を肘の位置に置くなど、たまに外れます。確認画面では、各投球の「構え」「振り出す直前」「最高点」の3場面を表示し、怪しい場面にはオレンジの印を付けます。丸をドラッグして直すと、その位置で数値を計算し直します。
- 解析結果の「3投の比較」では、3投を腕を振る瞬間で揃えて並べ、腕と体に線を引いてスロー再生できます。重ね合わせの表示と、その瞬間の手首・肘・肩のばらつき（cm）も出ます。
- 撮影した映像は解析結果の画面を閉じるまで端末のメモリにあるだけで、保存はしません。

## スコアと課題

- ラウンドごとに100点満点のスコアと、7項目（着弾の正確さ、グルーピング、構えの再現性、構えの静止、引きの真っ直ぐさ、振りの再現性、体の安定）の内訳を表示します。
- 一番伸びしろのある項目から「次はこうしてみよう」を1つだけ提案します。課題は解析結果の画面にだけ表示し、次のラウンドの結果で、前回の課題が良くなったかを表示します。
- 履歴の画面で、スコアの推移と項目ごとの平均を確認できます。

## 測っているもの

- 構えの位置（左右・高さ）と、投げるごとのずれ
- 投げる前の手の揺れ
- 引く時・振り出し中の横移動
- 手と肘の上がり幅
- 体の位置のずれ

数値は画面上の位置を前腕の長さ（身長から推定）でcmに換算した目安で、誤差はおよそ±1〜2cmあります。

## プライバシー

映像の処理はすべて端末の中で行い、外部には送信しません。ページには、自分自身のファイル以外と通信できない設定（Content Security Policy）を入れてあります。MediaPipeのライブラリが送ろうとする利用状況ログも、この設定で遮断されます。履歴はこのブラウザの中だけに保存され、「データを書き出す」でJSONファイルとして取り出せます。

## 構成

- `index.html`, `css/`, `js/` — アプリ本体（ビルド不要の素のJavaScript）
- `js/analysis.js` — 投球の検出と数値化、コメント生成
- `js/confirm.js`, `js/compare.js`, `js/frames.js` — 認識の確認画面、3投の比較再生、撮影コマの表示
- `vendor/mediapipe/` — MediaPipe Tasks Vision（Apache License 2.0）
- `models/` — MediaPipeの姿勢推定モデル（BlazePose）。npmの `@mediapipe/pose` に含まれるモデルに、`tools/make_task.py` で前処理用メタデータを付けてまとめたもの
- `sw.js`, `manifest.webmanifest` — オフライン動作とホーム画面への追加
